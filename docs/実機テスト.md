# 実機テスト：共鳴と倍率の重ね方

成長予測の計算が実際のゲームと合うかを、出撃して確かめるためのチェック表。
自動テスト（`tests/calc/test_engine.js`）の共鳴ケースと同じ内容。

## やり方

- 道具はなし、強化値は+0、神様の加護なしで出撃し、**Lv1（出発直後）**のステータスを見る。
  Lv2以降は成長に乱数が入るので、比べるのは Lv1 だけでよい。
- 手持ちの強化値が+0でないときは、成長予測にその強化値を入れて出た Lv1 と比べる。
- 「共鳴なし」の列は、その組み合わせで共鳴が効かなかった場合の値。実機がこちらと一致したら、共鳴の扱いが違う。
